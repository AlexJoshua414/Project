# Alex Joshua — Portfolio

A responsive frontend developer portfolio built with plain HTML, CSS and JavaScript.

## Quick start

Open `index.html` in your browser, or use VS Code Live Server.

## Before publishing

Edit these items in `index.html`:
- Email link: `your-email@example.com`
- GitHub link: `https://github.com/`
- WhatsApp link: `https://wa.me/`
- Add your future project links.

The first project is already connected to:
https://reigners-destiny-school-qa4o.onrender.com

## GitHub

1. Create a new GitHub repository, e.g. `alex-joshua-portfolio`.
2. Upload the contents of this folder.
3. Keep the repository public if you want clients to inspect the code.
4. Copy the repository URL.

## Render

1. Sign in to Render.
2. Choose **New → Static Site**.
3. Connect your GitHub repository.
4. Build command: leave blank.
5. Publish directory: `.`
6. Create the site.
7. Render will give you a live `.onrender.com` address.
8. Every time you push changes to GitHub, Render can redeploy the site.

## Adding a project

Duplicate one of the project cards in `index.html`, change the title/description/tags, replace the preview block with an image later, and add the live/GitHub links.

## Notes

The design intentionally uses no external framework so you can understand and customize the code while you are learning.
